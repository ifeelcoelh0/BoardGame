Reinos do Dragão — v0.99.42 Parte 2 — Replay Verifier

Base usada
- Construído sobre boardgame-v0.99.42-part2-base.zip enviado depois do checkpoint da Parte 1.
- Este ZIP contém apenas este README e o patch; não contém ficheiros src/ soltos para evitar sobrescritas acidentais.

O que acrescenta
- src/game/replayVerifier.js
  - reproduz o Action Journal pelo reducer central;
  - reutiliza os RNG, IDs e timestamps registados;
  - verifica actor, eventos, privateResult e fingerprints antes/depois;
  - devolve a sequência exacta e o motivo quando encontra divergência;
  - cria/serializa/lê um pacote técnico de replay marcado host-private.
- Checkpoints esparsos no Action Journal quando o estado autoritativo muda entre duas ações aceites (por exemplo disconnect/reconnect, takeover de bot ou limpeza de trade). Isto evita fingir que essas mutações externas foram ações do jogador.
- Append do journal deixa de clonar todas as entradas históricas a cada ação; copia apenas o array append-only.
- Testes de replay real com ROLL_DICE + PROPOSE_TRADE, RNG/ID determinísticos, corrupção deliberada e checkpoints.
- O verificador estático existente passa a validar também a infraestrutura de replay.

Aplicação
1. Colocar o .patch na raiz C:\Users\plc39\BoardGame
2. git apply --check reinos-do-dragao-v0.99.42-part2-replay-verifier.patch
3. Se não houver erro:
   git apply reinos-do-dragao-v0.99.42-part2-replay-verifier.patch
4. npm run checksums:update
5. npm run check
6. Depois correr Cypress como habitualmente.
