Objetivo

- O AudioSys escolhe primeiro a variante concreta 01/02.
- A mesma variante alimenta o ficheiro de áudio e a transcrição mostrada sob o banner.
- As 8 personagens têm 176 transcrições mapeadas para os 176 voice variants canónicos.

Aplicação
1. Colocar o .patch na raiz C:\Users\plc39\BoardGame
2. Verificar:
   git apply --check reinos-do-dragao-v0.99.40-exact-character-subtitles.patch
3. Se não houver output/erro:
   git apply reinos-do-dragao-v0.99.40-exact-character-subtitles.patch
4. Atualizar checksums e validar:
   npm run checksums:update
   npm run check
5. Teste manual recomendado:
   - uma reação/emote por personagem;
   - uma ação com variante 01/02 (village/trade/robbed);
   - Muriel: confirmar as duas falas de Victory, Robbed e Trade.

Não usar --reject nem forçar o patch se git apply --check falhar.
