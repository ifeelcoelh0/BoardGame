# Ícones pixel art

Colocar aqui o conjunto de ícones, preservando os ficheiros originais.

Na fase de GUI será criado um catálogo e um componente `GameIcon`; os nomes dos ficheiros não devem ser usados diretamente pelos componentes. Categorias iniciais sugeridas:

- `actions/`
- `resources/`
- `buildings/`
- `troops/`
- `cards/`
- `status/`
- `navigation/`
- `social/`
- `decorative/`
