Reinos do Dragão — v0.99.43 Parte 2: Recovery Matrix (Cypress)

Objetivo
- Acrescenta uma matriz E2E real de save/reload/resume no browser.
- Não altera regras nem o runtime de recovery; esta parte testa o comportamento atual antes de justificar novas correções.

Cobertura nova
- reload de um autosave real durante setup e resume do mesmo reino
- preservação exata do passo de setup
- decisões obrigatórias após resume
- limpeza de trade dirigido a convidado desconectado
- fim de partida + limpeza de readiness antigo de rematch
- continuação do Action Journal com checkpoint após recovery
- preservação de estado específico de Guerra e Exploração

Ficheiros
- cypress/e2e/recovery.cy.js (novo)
- cypress/helpers/recovery.js (novo)
- package.json
- scripts/verify-browser-tests.cjs
- scripts/verify-game-recovery.cjs

Aplicação
1) git apply --check reinos-do-dragao-v0.99.43-part2-recovery-matrix.patch
2) git apply reinos-do-dragao-v0.99.43-part2-recovery-matrix.patch
3) npm run checksums:update
4) npm run check
5) npm run e2e:serve
6) noutro terminal: npm run test:e2e

Validação feita sobre o ZIP-base exato recebido
- git apply --check: OK

Nota
