# Lobby 3D v3 — Câmara e composição

Esta passagem reorganiza o enquadramento do lobby sem alterar a lógica.

- Câmara mais afastada e ligeiramente mais alta.
- Mesa menos esmagadora e quatro lugares mais legíveis.
- Mais espaço no topo para o título, código e jogador superior.
- Etiquetas dos assentos reposicionadas para se ligarem melhor às cadeiras.
- Jogador local separado da barra de ações.
- Notificações deslocadas para não taparem o cabeçalho central.
- Movimento lateral da câmara reduzido.
