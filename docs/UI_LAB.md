# UI Lab — v52.2

Página interna disponível em `/?dev=ui` ou através de `npm run dev:ui`.

## Objetivo

Comparar três direções visuais antes de alterar a interface real:

- A — Madeira e bronze
- B — Heráldica medieval
- C — Fantasia pixelizada

A página contém exemplos de paleta, tipografia, botões, painéis, recursos,
feedback, seleção de personagem e banner de jogador.

## Limites desta fase

- O jogo normal não foi alterado.
- Nenhuma moldura apresentada é arte final.
- O ícone de cavalos está marcado como provisório.
- Os componentes do laboratório ainda não substituem os componentes legacy.

## Decisão seguinte

Escolher elementos específicos das três direções e consolidá-los num primeiro
sistema visual. Depois disso, aplicar o sistema à seleção de personagem real.
