# Lobby 3D v7 — mesa simples e props refinados

## Inclui
- Mesa simplificada para madeira simples, sem aros/placas centrais
- Tampo mais uniforme e escuro, mantendo textura de madeira
- Hexágonos mais visíveis, menos organizados e com melhor delimitação
- Caixa/tabuleiro com mais identidade
- Dados menores, brancos com pips pretos reais
- Velas e castiçais mais convincentes
- Caneca/tankard mais medieval
- Distribuição dos objetos menos “arrumada por algoritmo”
