# Lobby 3D v73 — refinamento dos retratos

## Objetivo
Melhorar os retratos provisórios da parede de seleção para que cada uma das 8 casas tenha uma leitura mais distinta e com mais caráter visual, preparando a futura implementação do movimento inicial de câmara.

## Alterações
- retratos procedurais redesenhados com linguagem mais rica e menos genérica;
- cada personagem passou a ter:
  - paleta própria;
  - fundo temático;
  - busto/silhueta mais específica;
  - símbolo e detalhes decorativos próprios;
- a placa superior foi reduzida e subida, para deixar de interferir com a fila superior de retratos;
- os retratos foram reposicionados verticalmente para melhorar a composição.

## Nota
Os retratos continuam a ser provisórios e deverão ser substituídos/refinados mais tarde, mas a parede já fica mais legível e mais preparada para a futura câmara de seleção.
